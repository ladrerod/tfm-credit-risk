\section{De un estudio amplio a un producto predictivo concreto}

El trabajo se acota a una probabilidad de impago a 24 meses calculada a partir de variables de originación. El producto final separa el compacto local, el entrenamiento y una API local de consulta. No es una herramienta de decisión crediticia.

\section{Datos y definición del problema}

El único fichero analítico es \texttt{freddie-pd24.csv.zst}. Según D-008, contiene cohorte, cinco entradas numéricas, fecha de disponibilidad de la etiqueta y el objetivo binario \texttt{default\_24m}; no conserva identificadores. D-006 documenta la preparación ciega y la madurez de las etiquetas antes de consolidar el compacto.

\section{Diseño experimental y validación temporal}

La selección usa folds anuales 2015--2017 con seis años de desarrollo, dos de calibración y tres de embargo. El ajuste de referencia usa 2010--2015 para desarrollo y 2016--2017 para calibración. Los años posteriores permanecen fuera de ese ajuste; 2023 es el holdout final.

\section{Cinco variables conservan la capacidad predictiva}

El contrato de entrada queda limitado a \texttt{origination\_fico}, \texttt{original\_dti}, \texttt{original\_cltv}, \texttt{original\_interest\_rate} y \texttt{number\_of\_borrowers}. D-007 registra que el challenger de dieciocho variables no superó la regla pareada material, por lo que el contrato no se amplió.

\section{Comparación y selección del modelo predictivo}

D-007 compara una regresión logística y un challenger de árboles sobre las cinco variables. La regresión logística se congeló tras la comparación temporal: el challenger no satisfizo la regla material de sustitución. Las transformaciones, la semilla y la calibración quedan fijadas antes de la evaluación posterior.

\section{Resultados del modelo seleccionado}

Esta sección reserva los resultados de evaluación temporal y del holdout para la evidencia que se incorpore después de la congelación. No presenta cifras finales ni utiliza el holdout para modificar el producto.

\section{Arquitectura del producto final}

El flujo es \texttt{freddie-pd24.csv.zst} hacia entrenamiento, bundle local y API. El bundle conserva el modelo, el esquema de cinco entradas, sus bandas de riesgo y hashes de datos e implementación. La API ofrece \texttt{GET /health} y \texttt{POST /predict}.

\section{Demostración y validación del producto}

La validación permanente cubre el lector, la separación temporal, el modelo, el bundle y el contrato de API. La solicitud de predicción exige exactamente las cinco entradas numéricas y devuelve un score, una banda relativa y una advertencia de uso académico.

\section{Conclusiones, límites y posibles mejoras}

PD24 es un producto académico mínimo para estimar probabilidad de impago a 24 meses con una superficie de ejecución reducida. Cualquier ampliación requerirá nueva evidencia y validación independiente.
